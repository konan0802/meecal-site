# meecal-site

iOSアプリ **MeeCal（ミーカル）** の公開サイト（GitHub Pages → https://meecal.app ）。

- 配信物: index / privacy / terms / support（日本語）と en/ の英語版、favicon、CNAME
- **原本は [kirokal](https://github.com/konan0802/kirokal) リポジトリの `docs/store/site/`**。修正は原本側で行い、このリポジトリへコピーして反映する
- 旧ドメイン `kirocal.jp`（[kirokal-site](https://github.com/konan0802/kirokal-site)）と `kirokal.jp`（[kirokal-redirect](https://github.com/konan0802/kirokal-redirect)）は、同じパスの meecal.app へ転送する（konan0802/kirokal#1054）
- DNS は Cloudflare（Registrar も Cloudflare）。.app は HTTPS 必須なので Pages の「Enforce HTTPS」を有効にする
